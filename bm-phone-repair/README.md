# BM Phone & Electronics Repair

A professional Next.js website for BM Phone & Electronics Repair services.

## Features

- 📱 Service listings with pricing
- 📝 Contact form with email integration
- 📱 Fully responsive design
- 🎨 Modern UI with animations
- 🔍 SEO optimized
- ⚡ Fast loading with Next.js

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion
- React Hook Form
- Zod Validation
- Nodemailer
